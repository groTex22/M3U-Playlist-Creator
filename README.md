# M3U Playlist Creator

Автоматическое создание `.m3u` плейлистов на базе **Python**.

Подходит для образов игр и медиа-файлов: **Dreamcast, PS1, PS2** и других платформ.

---

## ✨ Возможности

- 🔍 Рекурсивный поиск файлов в папке и подпапках
- 📦 Объединение multi-disc файлов в один `.m3u`
- 🧹 Автоматическая очистка от ненужных символов названий плейлистов
- ⚙ Поддержка произвольных расширений файлов
- 🪟 Удобный запуск через `.bat` (Windows)

---

## 🧠 Пример

**Файлы:**
```
Shenmue II CD1 Rus Kudos.cdi
Shenmue II CD2 Rus Kudos.cdi
Shenmue II CD3 Rus Kudos.cdi
```

**Результат:**
```
Shenmue II.m3u
```

---

## 🧹 Что автоматически удаляется из названия плейлиста

- `Rus`
- `Kudos`
- `CD1`, `CD2`, `CD3`
- `Disc1`, `Disc_2`, `Disc 3`

## 🖥 Требования

- **Windows**
- **Python 3.8+**


## ▶ Запуск

### 🔹 Вариант 1. Через BAT (рекомендуется)

Дважды кликните по файлу:

```
run_createM3U.bat
```

---

### 🔹 Вариант 2. Через командную строку

```bash
python createM3U.py "D:\Games" "cdi gdi chd"
```

**Аргументы:**

| Аргумент | Описание |
|--------|----------|
| Путь | Папка с файлами |
| Расширения | Список расширений через пробел или запятую |

---

## 📄 Поддерживаемые форматы

Можно указывать любые расширения, например:

```
cdi gdi chd cue iso mp3 mp4
```

---

## ⚠ Примечания

- `.m3u` создаётся **в папке с файлами**
- Исходные файлы **не изменяются**
- Плейлист создаётся даже для одиночных файлов

---

## 🛠 Кастомизация

Правила очистки имён находятся в `createM3U.py`  
и реализованы через **регулярные выражения**.
