# M3U Playlist Creator

Автоматическое создание `.m3u` плейлистов на базе **Python**.

Подходит для образов игр и медиа-файлов: **Dreamcast, PS1, PS2** и других платформ.

---

## ✨ Возможности

- 🧹 Автоматическая очистка от ненужных символов названий плейлистов
- ⚙ Поддержка произвольных расширений файлов
- 🪟 Завернуто в .exe файл

При каждом PR автоматически собирается новая версия .exe файла

## ▶ Запуск

### 🔹 Вариант 1. Запуск приложения

Открыть справа вкладку "Releases", скачать и запустить файл M3U Playlist Creator.exe

### 🔹 Вариант 2. Скачать репозиторий

Запусть исполняемый файл main.py в корневой папке 

```bash
python main.py
```
